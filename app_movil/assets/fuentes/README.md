# assets/fuentes/

Las mismas tipografías del panel web, incluidas dentro de la app para que
se vea igual aunque no haya buena conexión:

- **Sora** (pesos 500, 600 y 700): títulos y la marca "KairosTV".
- **Manrope** (pesos 400 a 800): todos los textos.

Están registradas en `pubspec.yaml` (sección `fonts`) y se usan desde
`lib/tema.dart` (clase `Letras`). Son libres (SIL Open Font License, ver
`OFL-Sora.txt` y `OFL-Manrope.txt`).
