# assets/fuentes/

La tipografía **Poppins** (pesos 400, 500, 600, 700 y 800), incluida dentro
de la app para que se vea igual aunque no haya buena conexión. Está
registrada en `pubspec.yaml` (sección `fonts`) y se aplica a toda la app
desde `lib/tema.dart`.

Es libre (licencia SIL Open Font License, ver `OFL.txt`).
