# html/

Las pantallas del diseño de Kairos TV, una por archivo (`mobile-*` para el
celular, `tv-*` para el televisor). Se abren en el navegador. Son la
referencia visual: la app real está en `app_movil/lib/movil/` y `app_movil/lib/tv/`,
y sus comentarios dicen qué pantalla de acá copian (ej. "tv-04").
