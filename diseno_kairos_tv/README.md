# Kairos TV · paquete de diseño

Prototipos de referencia para implementar en Flutter, con la marca final integrada.

## Carpetas

- `html/`: un archivo HTML con Tailwind por pantalla.
- `images/`: capturas PNG de los HTML (`1920×1080` TV y `390×844` celular).
- `brand/`: símbolo, logotipo, ícono de app y banner Android TV finales.
- `shared/theme.css`: tipografías, tokens y componentes visuales compartidos.
- `DESIGN.md`: sistema visual, foco y recorrido del control remoto.
- `SCREENLIST.md`: inventario y alcance de las 32 vistas.
- `tools/build.mjs`: regenera los HTML.
- `tools/capture.ps1`: regenera las capturas.

Los nombres, canales, títulos y contactos que aparecen son contenido de muestra para validar composición. La implementación debe reemplazarlos con la API; no se agregaron campos que hoy no existan.
